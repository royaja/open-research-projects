Communication on interest rates from Norges Bank

This project contains a descriptive content analysis of how Norges Bank communicates in recent English-language speeches and press releases.

Scope

Collection date: 2026-04-04
Source domain: Norges Bank's English-language website
Included material: 40 speeches and 40 press releases
Documents included: 80
Unit of analysis: paragraph
Public paragraph-level file: 1,622 rows
Analytic sample used in the figures: 1,406 paragraphs

This is a bounded corpus. It contains the most recent 40 speeches and the most recent 40 press releases available through the collection workflow on 2026-04-04.

Data note

The full text on the website is owned by Norges Bank and is therefore not included in the uploaded dataset. The public data file contains coded variables, dates, document types, source URLs, identifiers, and related metadata. The underlying website text is not redistributed in this project.
